首次由網站管理者登記一次。之後：登入Google → 建立／選擇活頁簿 → 自動同步。不必每次匯入JSON。

不會要求這些東西

不需要券商密碼、券商API私鑰、Google Client Secret、全部硬碟存取權。不要把私人帳本或Google權杖放入GitHub。

ChatGPT中的Google Drive連接，和這個網站的OAuth授權是兩件事。網站第一次仍需要你完成下列登記及同意；無法省略或假裝已授權。

管理者的一次性設定

  1. 使用自己的Google帳號開啟 Google Cloud Console，建立一個專案，例如 StockLab Personal。這套功能不要求開啟付費模型端點或升級配額。
  2. 在「API和服務 → 程式庫」，啟用 Google Sheets API 與 Google Drive API。
  3. 在「Google Auth Platform／OAuth同意畫面」填入應用名稱、支援電子郵件。個人測試選External／外部，保持Testing／測試；把自己的Google帳號加入Test users／測試使用者。
  4. 資料存取權只加入 https://www.googleapis.com/auth/drive.file。不要加入整個Drive的讀寫scope。
  5. 「Clients／用戶端 → 建立OAuth用戶端 → Web application／網頁應用程式」。在Authorized JavaScript origins／已授權的JavaScript來源填：
    https://flyree140.github.io
    只有協定與主機，不含 /GPT_stocklab/、index.html 或 #order。本機測試另加 http://localhost:8000。本版使用token popup，不設伺服器refresh token。
  6. 複製產生的Client ID，形如 123456-abc.apps.googleusercontent.com。這是公開應用識別碼，不是Client Secret。
  7. 回StockLab「雲端投資活頁簿」貼入ID並保存。一般使用從此只要按Google登入。
讓手機和電腦都不用重新貼Client ID

把部署包的 cloud-config.example.json 複製成 cloud-config.json，只填 client_id，提交GitHub。部署流程只發布這個公開欄位，不能放Secret或權杖。

{ "client_id": "你的ID.apps.googleusercontent.com" }

Google介面名稱可能調整；以Google官方設定文件為準。個人測試完成後，若要開放其他人使用，需另外完成對應的OAuth上線／驗證要求。

跨裝置、費用與故障處理

  • 換裝置：先登入同一Google帳號，用同一Client ID，選同一活頁簿，再同步。不會因登入就自動丟掉本機帳本。
  • 登入過期：權杖只在記憶體，不保存refresh token；重開頁面或過期需再次點登入。Google服務授權不能永遠免確認。
  • 帳務衝突：此個人版不是具有跨裝置原子鎖的交易資料庫。兩台同時花掉同一筆錢或賣同一持股，合併會報錯，不會默默刪掉某筆；停止操作並核對原始券商紀錄。
  • 設定衝突：明確按「以這台設定解決」，只合併設定版本，不刪交易。
  • 手改主紀錄：雜湊不一致會停止。更正應在網站記錄作廢或修正鏈，不能直接把格子數字塗掉。
  • 費用：標準Google Sheets API用途無額外費用，但有配額且政策會變。本版限制請求頻率，不要求升級配額／付費；自己的帳號若已啟用其他計費服務需另外管理。
  • 不要公開分享：不需將活頁簿設成「知道連結的任何人」。只在你自己的帳號存放。
  • 同源安全：Google OAuth origin為整個 flyree140.github.io。不要在同網域放入不可信第三方程式或公開個人備份。
