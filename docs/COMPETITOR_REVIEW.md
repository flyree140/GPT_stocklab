# 參考網站去蕪存菁

參考：`https://kmuftp-creater.github.io/tw-stock-analyzer/`

檢視日期：2026-08-29。功能與版本可能持續變動。

## 值得保留的部分

| 參考概念 | 新版保留方式 |
|---|---|
| 快速健康度 | 改成可拆解的新聞、技術、基本、籌碼、風險、完整度 |
| 股票篩選 | AND 條件、滑桿、儲存條件 |
| 技術指標 | SMA、RSI、MACD、KD、ATR、量比 |
| 支撐壓力 | 20 日區間，清楚標示只是歷史統計 |
| 籌碼摘要 | 使用 TWSE T86 |
| 收藏 | 不只 JSON 匯出入，增加 localStorage + Google Sheets |
| 排名 | 完整排名之外，再增加每天自動置頂 Top 5 |
| 熱度/一頁式閱讀 | 首頁市場新聞溫度與重點事件 |

## 不直接複製的部分

### 單一健康分

單一大數字很方便，但容易讓使用者忽略缺資料與風險。新版保留總分，並強制顯示分項、完整度與風險扣分。

### 規則式 AI 名稱

技術條件加權可以很好用，但不應只因為有綜合規則就稱為完整 LLM 新聞分析。新版把：

- 新聞原文證據
- 公司關聯性
- 來源品質
- 模型信心
- 影響機制
- 失效條件

全部放到事件卡片。

### 缺乏 point-in-time 鎖定

一般歷史圖表不等於無洩漏回測。新版將 `available_at`、snapshot 與 result 分離，並提供自動 validator。

### 收藏只在單一瀏覽器

JSON 匯出入仍可作備份，但個人日常使用更適合 Google Sheets 同步。新版保持 localStorage 為第一層，避免雲端不可用時影響操作。

## 新版的差異化

1. 每日抓取新聞並逐則評分，而不是只看技術條件。
2. 兩層免費開源模型 + 透明規則 fallback。
3. 每日最佳不是單純最高分，會套入完整度、關聯度與風險門檻。
4. 歷史回放預設看不到事後答案。
5. 每個輸入保留資料血緣與可用時間。
6. 可用 GitHub Pages + Actions 零伺服器部署。
