# 日常操作與你的歷史紀錄

## 開站先看什麼

「今日行動」先顯示可執行股數與第一個阻擋原因。價格過期、官方未核對時，0股就不開新單。
「條件式股數」是解除全部條件後的規劃，不是現在能買的數字。
股數單位是股，不是張。系統並未下單，停損／停利也不會自動送到券商。

## 想調整多少錢與時間

到「我的資金與目標」改可用資金、每次最多投入、想放幾天與想賺的淨額。
更改目標只重算新計畫；已保存的計畫不改，避免事後移動標準。
每月投入不是銀行扣款；開始實際記帳後，以已記錄且可用現金限制可買額度。
提高獲利願望不會提高槓桿或容忍虧損。目標價超過近期壓力時明確警示。

## 真的買過怎麼記錄

先按「記錄投入」填你實際放入投資帳戶的資金，再記錄券商成交。
逐筆填日期、股數、成交均價、手續費、證交稅。費用估算只是幫你預填，仍以券商為準。
沒有成交的委託不要填；只成交一部分就填實際部分。
連結先前行動單，之後可核對當初限價、停損、目標與持有期限。
成交後才建立的行動單不能證明你事前遵守；相同日期因沒有精確成交時間也不能確認先後。

## 成果怎麼看

- 已實現：已賣出部分的淨收入減FIFO分攤原成本。
- 未實現：仍持有的股數按最後可用收盤估值減剩餘成本，未扣未來賣出費用。
- 待交割：賣款先列待收，T+2才可在本帳本再次動用。
- 淨資產與投入差額：不把每月新增4,000元畫成交易獲利。
- 行情日期會列出；缺價或公司行動待核時，不把不可靠估值當確定損益。
- 顯示損益／總投入，是簡單帳務比例，不是年化、TWR或IRR。

填錯時按作廢保留更正鏈；若刪除買單會造成之後超賣，系統拒絕，需按依賴次序更正。

## 私密保存與備份

不需要帳號、Token或匯入才能開始。瀏覽器localStorage以網站路徑區分帳戶。
不同電腦／手機／瀏覽器不會自動同步。清除網站資料可導致遺失。
每次重要買賣後可按「下載私人備份」；換裝置時才用「還原」。另可下載CSV核帳。
原版Google Sheets僅收藏清單同步，並非這份真實成交帳的雲端備份。
私人備份、交易明細、身分或券商資料不可放進公開GitHub。
