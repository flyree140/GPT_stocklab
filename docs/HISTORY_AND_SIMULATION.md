# 歷史保存與試買

新快照：`data/snapshots/YYYY-MM-DD/run-時間戳.json`。manifest保存多個run及SHA256；相同日期重跑不修改舊run。較舊日期回填不把latest倒退，不截短較新市場歷史。

原v16日期檔繼續保留。Re-analyze工作流程用新規則追加run，mode為retrospective_reanalysis，產生時間是真實現在，不倒填成當時產生。

回到歷史快照時，前端只請求當時的快照；試買按下確認揭曉後才載入market檔。公開靜態檔不是權限隔離，技術使用者仍可自行讀取；真正嚴格盲測要另建私人結果後端。

試買：訊號日下一個有有效開盤的交易日進場、成本參數可調、跳空停損取開盤、日K同日雙邊保守停損優先。不拿收盤替代缺開盤，也不把未達持有期算已平倉。公司行動資料無法正確處理時停止，不輸出假可比報酬。

此版前端交付單筆試買及本機紀錄，不將重疊獨立交易的報酬硬乘成組合複利曲線。要作真實策略績效，仍需時間序列資金配置、滑價、流動性、除權息和樣本外驗證。
