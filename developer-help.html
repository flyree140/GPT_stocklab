開啟補抓行情工作流程

更新價格，不改寫原分析

最新向前計畫會重讀完整市場日K，重算尚未確認的價帶與股數，另存價格雜湊。原新聞、原標籤與分數保留原時間；不是說補價工作已重做全部六面向。歷史重播不讀最新價格作為當時決策，已確認試單也不被新行情改寫。

週末、盤中、關閉網頁的行為

一般交易時段為台北09:00～13:30，假日及特殊休市依日曆。試驗以完整日K回算，不是零股逐筆撮合。本頁使用Asia/Taipei轉換，但仍依你的裝置時鐘，請在系統開啟自動日期／時間。

勾選自動核對後，只有本頁開啟且可見時，每5分鐘讀已發布資料、處理已確認試單。歷史批次要先手動同意揭曉；不會自動新增買進。關閉頁面後，GitHub可繼續更新公開行情，但沒有你的私人瀏覽器試單，因此不會替私人帳戶日結。

PRIVATE GOOGLE DRIVE + SHEETS

連接你自己的開發者活頁簿

已經用主頁建立個人試驗活頁簿？這裡可以沿用同一個Client ID，但要在開發者頁再次登入，並建立／選擇獨立的開發者帳本。

已設定過Google：直接這樣做

  1. 到開發者頁第4個分頁「Google活頁簿」。看第①格是否顯示Client ID已設定；可沿用cloud-config.json或同瀏覽器的主頁設定。
  2. 按「登入Google」，選擇你要存檔的帳號並授權。登入只代表取得短效權杖，還沒存入資料。
  3. 按「尋找既有」。沒有「StockLab 開發者驗證」才按「建立新活頁簿」。不把個人實盤或PaperLab帳本拿來覆蓋。
  4. 按「保存全部並讀回核對」。必須看到已讀回核對的訊息，才算雲端保存成功。
  5. 按「打開我的Google活頁簿」。批次版本分頁保存分段JSON、版本與SHA-256。請勿手改主資料；平常從網站閱讀配置、成交與結果。

重新整理／換頁後可能需重登，Token只存在記憶體。不清除網站資料；登入Google也不會自動搬移另一台電腦的批次，要選回帳本並按「從雲端還原」。事件分岔會停下來，不靜默覆寫。

從未設定Google：一次性管理者設定

  1. 到 Google Cloud Console，建立或使用你的StockLab專案。
  2. 「API和服務 → 程式庫」啟用 Google Drive API 和 Google Sheets API。這個功能不需要付費模型API或API key。
  3. Google Auth Platform／OAuth同意畫面：填應用名稱與聯絡email；個人測試選External／外部、Testing／測試，把自己的Google帳號加入測試使用者。
  4. 資料存取只加入 https://www.googleapis.com/auth/drive.file，不要求全硬碟讀寫。
  5. Clients／用戶端 → 建立OAuth用戶端 → 網頁應用程式。已授權JavaScript來源填 https://flyree140.github.io，不要加/GPT_stocklab/、index.html或#。本版是瀏覽器token popup，不需要你建OAuth後端。
  6. 複製公開的Client ID（形如123456-abc.apps.googleusercontent.com），貼進開發者頁的Client ID欄位，按「保存ID並準備登入」。不是Client Secret。
  7. 希望各裝置都能讀到公開ID，可在Repository根目錄放cloud-config.json，僅包含下方欄位，再部署一次。
{ "client_id": "你的公開ClientID.apps.googleusercontent.com" }

不用把活頁簿公開分享。不把Google access token、GitHub token、私人批次或模型密鑰提交GitHub。
